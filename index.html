Step 2 — Check Tracking / Create Claims

Reads data/tracking.csv
This step classifies every shipment from authoritative tracking dates. A shipment is written to claims.csv when its earliest delivery attempt—or successful delivery when no earlier attempt exists—occurred after the applicable expected-delivery date. Canada Post makes the final eligibility decision; optional EST shipment date and service metadata do not block classification.
The test validates configuration, obtains an OAuth token when needed, and performs one Tracking API JSON lookup. The export action performs the same single request and writes only property paths, types, array lengths, safe enum-like values, and semantic validation results. It does not modify claim state, claims.csv, eligibility state, queues, or summary counts; neither action uses the legacy API or continues into the full run.
